# Freestyle Football Client

This repository contains snapshots of different **Promise Development’s Freestyle Football** clients, captured using **Volt Executor** on **Different dates**. (date should be specified in release name)

The original dump is preserved in [`11V11 Oct 3, 2026, unedited`](11V11%20Oct%203%2C%202026%2C%20unedited/) for reference, research, and archival purposes. `dumper.luau` is the script used to capture the snapshot.


## Cleaned Source

Cleaned Sources are files that preserve the exact behavior of the original, unmodified dumps but have been refined to make the code more readable and understandable to the average person. Code quality, formatting, and overall clarity have been improved. However, the underlying logic and functionality always remain completely unchanged.
